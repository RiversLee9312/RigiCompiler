# 验证要求与 MVP 应用验收（§7–§8）

> 本文件是 [STDLIB.md](../STDLIB.md)（Rigi 标准库 MVP 设计）的章节拆分，§ 编号与原文件一致；总目录与章节索引见该索引文档。

## 7. 验证要求

### 7.1 公共 API

- 泛型约束、继承/虚派发、普通函数挂起和跨协程限制须有可编译样例，尤其是动态 SB 根值和异构容器。
- 新 native 能力覆盖 VM/native，系统行为分别覆盖 Windows/Linux。
- 构建及提交前双平台 NativeAOT 全量验证遵循开发指南，不在本文保存易变测试计数。

### 7.2 有判别力的场景

- 集合：空集合、扩容、删除引用、自定义 equals、NaN 与正负零判等、Map/Set 插入顺序、Queue 回绕与扩容、可空元素与不存在的区分；验证成功修改使迭代失效、无效果的 Set.add/remove 不使迭代失效，以及迭代器各状态的错误优先级。
- 集合算法：单次枚举、及早求值与短路、空输入的 fold/any/all、浅复制容器独立性、稳定排序、NaN 排序及正负零；比较器失败时排序算法未修改原容器。Set/Queue 的显式 Array/List 转换保留顺序，恢复 Set 去重而 Queue 保留重复项，直接序列化及未标 Temporary 的 Serializable 字段仍拒绝它们。
- 字符与文本位置：32 位 char 的补充平面字面量/转换/Span 布局/JSON 往返、代理码点与范围外值拒绝、U+0000、组合字符与标量计数、字节和标量切片的合法/非法边界、零长度/越界/null、独立迭代游标、Span 导出的副本与容量限制，以及 UTF-8 各可能分块边界。
- 文本算法：空搜索串、未命中、split 空项/maxParts、replace 不重叠且不扫描新内容、trim 固定空白集合、join 单次枚举及异常、StringBuilder 结果独立性；补充平面与 BMP 字符的比较次序在 VM/native 一致。
- Unicode 大小写：固定数据版本的无条件映射、一对多展开（ß→SS、İ→i + U+0307）、上下文独立（Σ 在词尾也得到 σ）、有条件映射排除、无映射字符保持、输出容量检查，以及不同 OS/系统语言/locale 下相同结果；不以宿主大小写函数或 Case Folding 的输出充当预期值。
- 数值文本：八种整数及 float/double 的静态扩展调用、parse/tryParse 返回各自目标类型及可空类型、IntegerRadix 默认 Decimal 与各显式枚举值、十进制读 `0xFF` 得 0、Hexadecimal 必需的前缀及大小写/符号位置、Binary/Octal 不识别 `0b`/`0o` 而读取数字前缀 0、首个非该进制数字处停止、后缀不致失败、无有效数字及前导空白失败、前导零按所选进制解释、各整数宽度上下界、溢出不截短为成功值、补码误解释拒绝、浮点完整消费/舍入/次正规数/负零/超限/特殊值、parse 与 tryParse 一致，JSON 仍拒绝非法数字尾部。
- 流：短读写、EOF、零长度、无效范围、中途失败、关闭与挂起清理；精确读取跨多次短读完成、提前 EOF 的请求/实际字节数及部分缓冲区保留、其他 I/O 错误原样传播；ISeekableStream 的位置、越过末尾的读写及补零。
- 缓冲与传输：普通内存流的独立副本、AutoBuffer 动态扩容及两类可定位流、独立游标与顺序追加可见性、关闭视图不清空内容、pipe 的累计计数/有界工作缓冲/不关闭不刷新、readAll 上限、输入预读与关闭后不回退。
- 所有权与收尾：StreamWrapperOwnership 默认 Borrowed 与显式 Owned、构造失败时的关闭责任、逐层 flush 后继续写入、flush 完成及失败传播、dispose 中编码/刷新失败仍执行必要清理、失败后对象关闭且重复 dispose 不重试、故障流清理不重写不确定数据、既有单异常展开语义、标准句柄不被误关；标准输出由宿主重定向到文件时仍验证已定的持久化刷新语义。
- 文本与标准流：UTF-8 BOM/非法编码/替换模式、空输入/空行/末尾无换行/CRLF 跨块、结果字节上限、普通 writeLine 不自动刷新、Console 经流实现后的公开 API 原子性与标准输出重定向。
- 通用便利读写：同一 TextReader/TextWriter API 在内存、AutoBuffer、标准流及文件流上工作；整体读取只消费剩余内容并遵守上限，整体写入不隐含截断、追加定位、flush 或关闭，默认 Borrowed 与 Owned 的收尾仍按既有规则执行。字节结果只使用 Span，动态缓冲继续通过 pipe 衔接 AutoBuffer。
- 路径：平台分隔符、盘符/UNC/相对路径、同操作固定基准、空文本/NUL/隐含盘符形式拒绝、无通配符或环境展开、join 的绝对参数拒绝、不同根的 relativeTo、纯文本 equals/hash、点文件扩展名、尾部分隔符及长路径；normalizeLexically 与链接解析区分，getRealPath 要求存在且不充当文件身份。
- 文件信息与链接：普通文件/目录/链接/其他种类、长度与纳秒时间、缺失字段为 null、权限和类型错误不折叠成不存在、断链与 followLinks 两种查询、junction、原生名称编码错误；信息记录不自动刷新，Path/信息序列化不恢复句柄。
- 目录：流式读取与整体列表、隐藏项和无 `.`/`..`、种类提示缺失、条目绝对路径、上限及中途错误、结束后的 read、故障和关闭状态、提前离开后的 using 清理；外部增删不冒充快照，非法名称不被跳过，create/createAll 的已存在与部分创建行为。
- 文件打开与修改：五种输出模式及只读入口、CreateNew 竞态、非截断保留内容、追加每次写到末尾、EOF 后可见新增内容、getLength 的实时查询、setLength 截短与零扩展/游标保持、负值/范围失败、默认共享、宿主默认权限、持久化刷新与失败后关闭。
- 删除与临时资源：删除文件/空目录/链接与目录链接、不误删链接目标、非空目录和只读失败、不存在的特定处理；显式临时目录、原子创建时的名称冲突、返回流的关闭责任、关闭不删除及原生资源无泄漏。
- 复制与移动：CreateNew/Overwrite 及目标链接、同一路径和不同硬链接的自复制拒绝、截断前检查实际打开对象、复制部分失败保留目标、成功返回前刷新/关闭；NoReplace 竞态及不支持时的错误、Replace 不覆盖目录、移动链接本身、跨文件系统不退化成复制删除，单异常清理规则与各平台错误映射。
- 序列化：动态 null 与缺失的区分、公开迭代不泄漏哨兵、Parcel 合法字段及元数据隔离；严格拒绝多余/缺失字段、错误数值宽度、double 到整数转换和不匹配的泛型容器；合法多态、空容器、深复制/消息/图模式的语义、别名、自环和非法图引用。
- JSON 类型：已知/未知/嵌套/多态类型标识、泛型完整类型名、枚举 case 与载荷、字段按声明直接构造值；`readAs` 对无标识对象、String 键 Map、空容器及运行时目标类型的解释；普通业务键不被误认成元数据。
- JSON Map 与互操作：键值对数组的空值/插入顺序/String 与非 String 键/恢复后重复键/非法条目；`keepTypeInfo=false` 递归去除格式元数据和 Map 包装、拒绝非 String 键 Map、两种枚举形态和 case 字段冲突，普通对象的 content/case 字段保留。
- JSON 格式：固定外部样例、整数边界、float/double 舍入和负零、非有限值、转义与跨块 token、转义还原后的重复成员名、尾随数据、实际编码的字节偏移、深度/输入/token 上限及显式编码配置；无环重复引用展开、真环与图模式拒绝、部分输出失败、I/O 与恢复异常原样传播、不关闭不刷新及顺序复用。
- 时间值与文本：负纳秒的规范化、完整精度比较/运算、总量向零截断、边界与溢出、闰年/无效日期、数值偏移及 UTC 范围；DateTime 严格格式、TimeSpan 的 ISO 日时分秒子集与规范输出，拒绝年/月/周、混合符号、空分量及超过九位小数；恢复对象时同样校验不变量。
- 时钟与计时：墙上时钟变化不影响单调计时，单调读数允许相等，跨 Worker 使用同一进程时钟域；覆盖等待时间、系统睡眠排除、Stopwatch 启停/复位、Timer 正的不足一毫秒部分向上取整及过去期限处理。区分纳秒表示精度与宿主实际分辨率。
- 数学：各整数宽度和最小有符号数绝对值、两种舍入模式、clamp 的无效区间及 NaN、正负零、无穷、定义域与次正规数；sqrt 正确舍入及超越函数 4 ULP 误差使用独立高精度参考验证，特殊值分类单独核对，不能只将两个后端互相比较作为正确性依据。
- 随机数：固定种子及混合 API 调用的已知输出向量在 VM/native、Windows/Linux 一致，覆盖 SplitMix64 初始化、各整数宽度、跨零范围、拒绝采样、单值范围、浮点端点、bool 位选取、字节序及尾块丢弃；无效范围不推进状态，空填充不推进状态，填充边界检查不改缓冲区，无参构造的系统随机源失败按约定传播。

JSON 不能只有自编码/自解码往返测试，两端可能共享同一个错误。语法兼容性使用固定外部样例或独立解析器；Rigi 特定映射使用明确的预期文档。
资源测试同时检查 native 内存台账、IDisposable 遗漏诊断和系统句柄生命周期，仅零台账泄漏或零退出码不足以证明外部资源清理正确。

后续进程环境另行覆盖入口参数、环境变量、进程当前目录及平台信息，不作为首版验收要求。

## 8. MVP 应用验收

1. **配置转换**：内存流或标准输入中的 JSON → JsonSerializer → Serializable 对象 → 修改 → 内存流或标准输出；覆盖坏 JSON、类型不匹配和正确关闭，不依赖路径或命令行参数 API。
2. **数据处理**：从内存流或标准输入逐块/逐行读取 UTF-8 → 集合转换与聚合 → 使用数学 API 计算 → 输出；注明保留全部数据的步骤，验证输入大于缓冲区时仍正常。
3. **对象状态往返**：在一致的应用状态点取得 Parcel → 将 JSON 写入 AutoBuffer → 通过其输入流读回并恢复对象 → 继续处理消息；保留 Rigi 对象类型、字段按目标声明解释，不支持环形引用，无环重复引用展开为独立副本。
4. **时间与耗时**：按 §4.9 解析和输出 DateTime 与 ISO Duration 文本、执行纳秒时间值运算，并以单调时钟和 Stopwatch 测量上述处理过程；验证 VM/native 一致的公共行为。
5. **文件保存恢复**：使用程序中给定的 Path 显式选择模式打开文件流，交给 JsonSerializer 写入并按 using 关闭，再打开读回恢复对象；文本文件同样由流组合 TextReader/TextWriter 处理。覆盖不存在、坏 JSON、类型不匹配、持久化刷新和资源关闭，不依赖路径内容便利 API、命令行参数或环境变量 API。
6. **可复现随机数据**：使用固定种子的 Random 生成有界整数、浮点和字节数据，交给集合与数学 API 处理；相同调用序列在各后端和平台产生相同输入数据。
7. **目录与文件管理**：在显式给定目录内创建子目录及临时文件，使用 DirectoryReader 遍历，再按确定的复制/移动/删除规则管理文件；覆盖提前停止读取、已有目标冲突、链接条目和失败后的部分结果，所有资源均经确定性清理。

对象快照不自行提供数据库隔离；文件流 flush 提供系统持久化刷新，但文件输出不自动构成原子替换或包含目录项的恢复事务。文件系统按 §4.5 与 D5 的已定契约验收。验收组合各模块能力，不把数据库、网络、进程环境或私有二进制格式带入 MVP。
